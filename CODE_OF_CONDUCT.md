# Code of conduct

Be kind and be direct. Disagree about the work, not about the person, and assume good faith.

racklint adopts the Contributor Covenant, version 2.1, by reference. Read it
[here](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in all project spaces:
issues, pull requests, discussions, reviews and any other place where someone speaks for or about the project.

## Reporting

To report a breach, contact the maintainer, [@riskand](https://github.com/riskand), on GitHub. The maintainer
will keep the report private.

A security issue is not a conduct issue. Report it as [SECURITY.md](SECURITY.md) says.
